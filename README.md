# Transcribe

Локальная транскрибация аудио и видео на Mac: файлы, папки и ссылки (YouTube, Rutube, Kinescope). Распознавание идёт на компьютере, записи никуда не загружаются.

Здесь лежат только установочные файлы. Скачать последнюю версию — в разделе [Releases](https://github.com/xbumixx-code/transcribe/releases).

- Требования: Mac с Apple Silicon (M1 и новее), macOS 14 или новее.
- Пробный период: 10 распознаваний, затем одно в день. Бессрочная лицензия на один Mac — $49.
